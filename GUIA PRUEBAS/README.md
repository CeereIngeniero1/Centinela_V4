# GUIA PRUEBAS — Centinela V4

Documentación **general** para preparar cualquier bot `.js` en modo **prueba** (sin radicación automática final y correo restringido a soporte).

Válida para **cualquier nombre de archivo**, hoy o en el futuro. Lo único obligatorio es que **tú indiques qué archivos** deben modificarse.

## Archivos en esta carpeta

| Archivo | Para quién | Uso |
|---------|------------|-----|
| [GUIA_PREPARAR_SCRIPTS_PRUEBA.md](./GUIA_PREPARAR_SCRIPTS_PRUEBA.md) | Personas | Paso a paso genérico con ejemplos antes/después |
| [PROMPT_PARA_IA.md](./PROMPT_PARA_IA.md) | IA / Cursor | Prompt reutilizable; **exige lista explícita de archivos** |

## Inicio rápido

1. Elige qué `.js` van a modo prueba (escríbelos en una lista).
2. Opcional: duplica el original antes de editar.
3. Aplica los 2 cambios de la guía **o** usa el prompt para IA con tu lista.
4. Revisa el checklist antes de ejecutar.

## Los 2 cambios (siempre iguales)

1. **Eliminar** bloque Continuar → captcha → Radicar (después de documentos).
2. **Correo:** comentar lista de producción; activar solo `Soporte2ceere@gmail.com`.

## PDF (opcional)

Abre `GUIA_PREPARAR_SCRIPTS_PRUEBA.md` en Cursor → Imprimir → **Guardar como PDF**.
